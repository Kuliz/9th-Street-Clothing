# 9th Street Clothing 🚀
### Premium Urban Apparel & Footwear Sourcing | Lusaka, Zambia

This is the official web platform for **9th Street Clothing**, an urban fashion brand focused on high-quality streetwear and global footwear sourcing.

## 🔗 Live Website
Check out the live store here: https://kuliz.github.io/9th-Street-Clothing/

## ✨ Key Features
* **Responsive Design:** Optimized for all devices, from mobile phones to large desktops.
* **The Kick Vault:** A dynamic product grid for premium footwear.
* **Integrated Payments:** Clear documentation for Airtel Money, MTN MoMo, and Bank transfers.
* **WhatsApp Integration:** Direct customer-to-hustler communication for seamless ordering.
* **Fintech Aesthetic:** A modern, high-contrast theme (Red, White, Blue, Black, and Neon Green).

* ## 📁 Project Structure
* `index.html` - The landing page and brand introduction.
* `products.html` - The "Kick Vault" with dynamic product listings.
* `payments.html` - Secure payment method details and verification.
* `about.html` - The story and vision behind the brand.
* `contact.html` - Social media and WhatsApp links.
* `style.css` - Unified global styling for the entire site.
